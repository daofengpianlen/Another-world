在 SillyTavern「世界书」新建条目，名称与开关如下，内容复制对应「===== 内容开始 =====」块。

【重要】条目名称必须完全一致（含 [initvar]、[mvu_update] 前缀）！

================================================================================
条目 1：[initvar]变量初始化勿开
================================================================================
开关：关闭（禁用）
激活：蓝灯
插入：角色定义之前
递归：不可被其他条目激活；不可激活其他条目

说明：名称含 [initvar] 时，MVU 在「新建聊天」时自动写入第 0 楼 stat_data。
      条目必须禁用，否则每轮会重置变量。

----- 内容开始（复制到世界书，不要带本行） -----
主角:
  头像: ''
  姓名: 旅人
  性别: 未知
  性格: ''
  外貌: ''
  身份: 冒险者
  等级: 1
  能力:
    生命: 100
    力量: 10
    体魄: 10
    智慧: 10
背包: {}
邂逅名录: {}
已解锁CG: {}
----- 内容结束 -----

条目 3：[mvu_update]变量更新规则
================================================================================
开关：开启 | 蓝灯 | 系统深度 0 | 递归双不可

----- 内容开始 -----
---
变量更新规则:
  主角:
    姓名:
    性别:
    身份:
    等级:
      type: number
      range: 1~100
      check:
        - 重大战斗胜利、完成关键任务、长期修炼后才会提升
        - 单次变化通常不超过 ±3，除非剧情明确说明大幅成长
    能力.生命:
      type: number
      check:
        - 受伤、治疗、升级、装备变更时调整
        - 单次变化应合理，重伤可大幅下降，治疗逐步恢复
    能力.力量:
      type: number
      check:
        - 获得武器、技能突破、等级提升时调整
    能力.体魄:
      type: number
      check:
        - 获得防具、体质成长、等级提升时调整
    能力.智慧:
      type: number
      check:
        - 学习、技能、状态异常时调整
  背包:
    type: |-
      {
        [物品名: string]: {
          描述: string;
          数量?: number;  // 默认为 1
        }
      }
    check:
      - 获得、消耗、丢弃物品时 insert 或 replace 数量
      - 数量归零后 remove 该物品条目
      - 不要一次性添加过多无关杂物
  邂逅名录:
    type: |-
      {
        [NPC名: string]: {
          性别: string;
          身份: string;
          等级: number;
          能力: { 生命: number; 力量: number; 体魄: number; 智慧: number };
          外貌穿着: string;
          内心想法: string;   // NPC 当前心理，随剧情更新
          位置: string;
          好感度: number;     // 0~100
          性欲: number;     // 0~100
          近期性经历: string;
        }
      }
    check:
      - 新 NPC 首次重要登场时用 insert 写入完整对象（不要包含头像；头像由程序按 NPC 名自动匹配）
      - 已存在 NPC 用 replace 或 delta 更新对应字段
      - 好感度根据 NPC 对主角行为的感知调整 ±(3~8)，仅在 NPC 知晓该行为时更新
      - 内心想法、位置应随当前场景及时更新
      - 路人、仅一句话出现的角色不必写入邂逅名录
  已解锁CG:
    check:
      - 通常由前端界面根据 background 自动解锁，AI 无需主动更新
      - 若剧情明确强制解锁某 CG 且界面未触发，可 insert 对应 URL 字符串到数组
----- 内容结束 -----
