角色CG白名单:
  说明: |-
    `<background>` 使用角色 CG 时，正文必须是 **「角色名 + 场景名」直接拼接**，中间无空格、无斜杠、无 catbox 文件名。
    前端仅识别本条目列出的 **7 位角色** 与其 **下方逐条列出的场景名**；写错一字、自创同义词、合并/拆分场景名都会导致背景无法显示。
    **无 CG 资源的角色**（白璃、绯夜、埃尔温娜、瑟拉菲娜、紫苑、莱克斯、修伦、亚修等）**禁止**写 `<background>角色名+场景</background>` 形式的 H 场景；请改用《艾瑟兰地理》中的地图次级区域名（如 `召唤祭坛`、`魔王封印间`）。
  命名规律:
    格式: <background>{角色名}{场景名}</background>
    示例: <background>莉莉安口交</background>、<background>凛正常位做爱射精</background>
    通用阶段_按亲密递进:
      - 接吻
      - 自慰 → 自慰高潮（动作视频 + 高潮静止图）
      - 摸胸
      - 手交 → 手交射精
      - 足交 → 足交射精
      - 乳交 → 乳交射精
      - 口交 → 口交射精
      - 破处相关（见各角色差异；夏洛特无此项）
      - 体位做爱 → 对应做爱射精（动作视频 + 射精静止图）
      - 做爱事后结束
    体位场景名_固定用词:
      - 正常位做爱 / 正常位做爱射精
      - 女上位做爱 / 女上位做爱射精
      - 后入位做爱 / 后入位做爱射精
      - 抱起做爱 / 抱起做爱射精
      - 侧身抬腿做爱 / 侧身抬腿做爱射精（**仅凛**）
    破处命名_因角色而异:
      - 凛、艾莉亚、伊洛丝、莉莉安: 破处、破除射精
      - 加洛琳娜、莉娅: 破处做爱、破除做爱射精
      - 夏洛特: **无**破处类场景
    射精静止图规则: 凡带「射精」后缀的场景均为 .png 静止图；无「射精」后缀的同名动作为 .mp4 视频（前端自动匹配，AI 勿写文件名）。
  禁止:
    - 自创场景名：舌吻、深喉、骑乘、后入、正常位、莉莉安做爱、口爆、颜射、高潮、事后 等未在白名单出现的词
    - H 场景仅有文字描写却**不插入** `<background>角色CG</background>`（7 位有 CG 角色**必须**插入）
    - 斜杠写法：抱起/做爱、口交/射精
    - 空格或分隔符：莉莉安 口交、莉莉安·口交
    - catbox 短文件名或 https 直链（除非无别名且无 CG 时的普通场景图）
    - 为无 CG 角色编造 H 场景 background
    - 把 CG 场景名写进 pic 表情（pic 仅 12 种表情；H 场景只写在 background）
