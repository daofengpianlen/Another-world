变量列表:
  说明: |-
    【权威结构定义】本条目定义 stat_data 全部键名、类型、默认值与手机界面映射。
    AI 读写变量时**只能**使用本条目与 initvar 中的键名；禁止自创根键或改键名。
    运行时当前值由下方 <status_current_variable> 注入；zod 定义见项目 schema.ts。
    配套条目：initvar · MVU格式要求 · 变量输出格式 · 变量更新规则 · GAL输出格式。

  stat_data_根结构:
    type: object
    子字段:

      当前时间:
        type: string
        默认: ""
        AI: replace
        示例: "今州历·云陵谷 08:30"
        界面: 手机「状态」顶栏 · 浪潮状态栏

      所在地点:
        type: string
        默认: ""
        AI: replace
        示例: "瑝珑-今州·云陵谷·临溪草坡"
        界面: 手机「状态」顶栏

      剧情显示:
        type: string
        默认: ""
        AI: 只读（_storyState + STORY_MAP 自动同步）
        示例: "v1.0 Part 1: 万象新声"
        界面: 手机「状态」「剧情」

      是否为后日谈:
        type: '"true" | "false"'
        默认: "false"
        AI: 只读（开场/指令系统）
        界面: 手机「剧情」

      当前长期目标:
        type: string
        默认: ""
        AI: replace（章节切换或目标变更时）
        界面: 手机「状态」「剧情」

      当前演绎事件:
        type: string
        默认: ""
        AI: replace
        说明: 当前章节/大事件名
        界面: 手机「剧情」

      当前演绎事件节点:
        type: string
        默认: ""
        AI: replace
        说明: 当前小节/节点
        界面: 手机「剧情」

      即将进行的下一个事件节点:
        type: string
        默认: ""
        AI: replace
        界面: 手机「剧情」

      已完成的上一个事件:
        type: string
        默认: ""
        AI: replace（章节切换时写入旧事件）
        界面: 手机「剧情」

      已完成的上一个事件节点:
        type: string
        默认: ""
        AI: replace
        界面: 手机「剧情」

      章节终止条件:
        type: string
        默认: ""
        AI: replace
        界面: 手机「剧情」

      主角信息:
        type: object
        AI: 部分 replace
        子字段:
          是否是漂泊者: { type: boolean|string, 默认: true, AI: 只读 }
          性别: { type: string, 默认: "男", AI: 只读 }
          身份与额外设定: { type: string, AI: 开局/重大身份揭露时 replace }
          当前状态: { type: string, 默认: "", AI: replace }
          当前穿着: { type: string | WearObject, 默认: "", AI: replace }
          性爱状态:
            type: object
            子字段:
              是否正在性爱: { type: boolean|string, 默认: false }
              高潮进度: { type: number, 范围: 0~100, 默认: 0 }
              高潮计数: { type: number, 范围: 0~999, 默认: 0 }
              _高潮次数上限: { type: number, 范围: 1~99, 默认: 5 }
          物品栏:
            type: Record<物品名, InventoryItem>
            InventoryItem: { 数量: number, 描述: string, 类型: string }
            AI: insert /主角信息/物品栏/{名} 或 delta 数量
            界面: 手机「状态」物品栏

      NPC漂泊者:
        type: object
        AI: 只读
        子字段:
          是否存在: { type: boolean|string, 默认: false }
          性别: { type: string, 默认: "女" }

      女性角色:
        type: Record<角色名, HeroineEntry>
        默认: {}
        AI: add/insert 首登场；replace/delta 已登场
        界面: 手机「状态」人际关系 ·「好友」·「信息」
        说明: 无 insert/add 则好友列表为空

      剧情触发器:
        type: array<TriggerItem>
        默认: []
        TriggerItem: { 事件类别, 事件简述, 状态, 事件计时 }
        AI: insert /剧情触发器/-
        界面: 手机「剧情」明线

      伏笔:
        type: array<ForeshadowItem>
        默认: []
        ForeshadowItem: { 伏笔内容, 指向的预期结果 }
        AI: insert /伏笔/-
        界面: 手机「剧情」暗线

      _storyState:
        type: { majorVerIdx, partIdx, isPostScript, _anchorVer }
        AI: 只读
        说明: 开场面板维护

      指令:
        type: { 推进剧情, 跳转版本, 修改后日谈模式为 }
        AI: 只读

      contact:
        type: Record<角色名, LegacyContact>
        默认: 不在 initvar 预置
        AI: 可选 add/replace
        说明: legacy 小爱结构，与 女性角色 双写时手机 merge
