鸣潮 — 世界书 / MVU / 脚本 部署清单
================================================================================

一、世界书必备条目（名称须含前缀，便于 MVU / 开场脚本识别）
--------------------------------------------------------------------------------
┌─────────────────────────────┬──────────┬────────────────────────────────────┐
│ 条目名称                    │ 启用     │ 内容文件                           │
├─────────────────────────────┼──────────┼────────────────────────────────────┤
│ [initvar]变量初始化勿开     │ 必须关闭 │ 世界书/变量/initvar.yaml           │
│ 变量列表                    │ 开启     │ 世界书/变量/变量列表.txt           │
│ [mvu_update]变量更新规则   │ 开启     │ 世界书/变量/变量更新规则.yaml      │
│ [mvu_update]变量输出格式   │ 开启     │ 世界书/变量/变量输出格式.yaml      │
│ GAL输出格式                 │ 开启     │ 世界书/格式/GAL输出格式.txt        │
│ [opening]                   │ 开启     │ 空或 YAML，保存开场面板状态        │
└─────────────────────────────┴──────────┴────────────────────────────────────┘

二、酒馆助手脚本（推荐组合）
--------------------------------------------------------------------------------
  MVU（MagVarUpdate）     必开
  鸣潮变量结构            必开 → 注册 stat_data zod schema，补全女性角色等缺字段
  鸣潮共享                必开 → WuWaShared.STORY_MAP、calculateStoryLogic
  鸣潮开场                必开 → 第 0 楼开场面板、自动 generate 开场
  鸣潮伪同层              必开 → 鸭子 GAL + 输入框 + 内置小爱手机
  鸣潮手机                默认关 → 已内嵌进伪同层，无需重复启用

  原 regex（鸣潮开场、鸭标签、旁白、大头像气泡等）请【关闭】，避免与脚本重复渲染。

三、第一条消息
--------------------------------------------------------------------------------
  第 0 楼 assistant 消息须含标记：[角色创建与故事开场]
  AI 生成第一条含 <gal> 的回复后，伪同层自动挂载；仅 StatusPlaceHolder 不算完成。

四、AI 每轮回复最低要求
--------------------------------------------------------------------------------
  1. <gal>…</gal>  — 剧情正文（<p> 旁白；漂泊者+女性角色 只用 <z>；次要路人 只用 <other>；禁止混用）
  2. <options>…    — 可选，快捷行动建议
  3. <StatusPlaceHolderImpl/>
  4. <UpdateVariable> + JSONPatch — 有状态变化时必填

五、当前仍缺 / 需自行补充的世界书内容（本仓库未包含）
--------------------------------------------------------------------------------
  □ [STORY_MAP]           — 可选；无则使用鸣潮共享脚本内置 STORY_MAP
  □ 各版本「主线章节 / 演绎事件」— 驱动 当前演绎事件、章节终止条件 等字段
  □ 角色设定 / 地理 / 文风   — 原角色卡世界书主体内容
  □ 剧情指令（如何使用 指令.推进剧情 等）— 若卡面有版本跳转功能
  □ 示例 assistant 楼层      — 见 世界书/示例/完整首楼回复示例.txt
  □ MVU zod schema            — 见 src/鸣潮/schema.ts + 脚本「鸣潮变量结构」

六、initvar 与开场面板联动
--------------------------------------------------------------------------------
  开场面板点击「开启我的索拉里斯之旅」会：
  · 写入 0 楼 stat_data（主角、NPC漂泊者、_storyState、剧情显示、所在地点、女性角色骨架）
  · safeReplace 世界书 [initvar] 内 majorVerIdx / partIdx / 是否是漂泊者 等占位
  · 写入 [opening] YAML（UI 表单回显）
  · 自动 generate 开场剧情（须返回 <gal>）
